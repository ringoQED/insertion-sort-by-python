# insertion-sort-by-python
Just a very simple and fundamental excercise for sorting an array of numbers.

Why I build it?
===============
I am a very beginner of Python. This is just a rudimentary excercise of doing sorting using Python. I tried not to use any library, built-in sorting function from Python and developed the algorithm by myself.

How does it work?
=================
It works by letting the user to enter a list of numbers in the terminal. The program will store the numbers in an array, then it will parse the array from start to finish. Whenever it sees that there is a number with a higher position index is greater than that with a smaller index, than it swaps these two numbers. It continues to parse the array until all numbers inside are in the order from the smallest to the largest.

I know that Python has a built-in sorting function called Timsort that can be used with more efficient time complexity, but I kind of avoiding to read the Python doc and asking myself what it would look like if it is done manually. It turns out that my version is just an insertion sort.

How to run it?
==============
1) Open a terminal in your OS
2) Type "python3 sorting.py" and press Enter
3) Enter the nos. to be sorted line by line, a blank line will exit the program
